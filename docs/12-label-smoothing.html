손실 함수: 너무 확신하지 않게

  • 원본: 정규화 → 레이블 스무딩 · 손실 계산

정답 토큰에 확률 1을 주는 one-hot 대신, 정답에 0.9, 나머지에 0.1을 나눠 준 분포를 목표로 학습한다. 논문은 이를 label smoothing($\epsilon_{ls}=0.1$)이라고 부른다. 모델이 지나치게 확신하지 않게 되어 perplexity는 조금 나빠지지만 정확도와 BLEU는 좋아진다.

LabelSmoothing: 목표 분포 true_dist를 만든 뒤 모델의 로그 확률과의 KL divergence를 손실로 쓴다. - 모든 칸을 smoothing / (size - 2)로 채운다. 2를 빼는 이유는 정답 칸과 패딩 칸을 제외하기 때문이다. - 정답 칸(scatter_)에 confidence = 1 - smoothing을 넣는다. - 패딩 열은 0으로 만들고, 정답 자체가 패딩인 행(문장 뒤 채움)은 통째로 0으로 만들어 손실에서 뺀다.

SimpleLossCompute: generator를 거쳐 손실을 계산하고 토큰 수로 나눈다. 두 값을 돌려준다. 하나는 기록용 합계(sloss.data * norm)이고, 하나는 backward()를 부를 텐서(sloss)다.

실행 결과에서 볼 것

  • 원본의 example_label_smoothing: 정답 칸 0.6, 나머지 0.133씩, 패딩이 정답인 3번째 행은 전부 0이다.
  • 원본의 penalization_visualization: 정답 확률을 계속 키우면 손실이 내려가다가 다시 올라간다. 지나친 확신에 벌점을 준다는 뜻이다.

151 return x + self.dropout(sublayer(self.norm(x)))
152
153
154class EncoderLayer(nn.Module):
155 "Encoder is made up of self-attn and feed forward (defined below)"
156
157 def __init__(self, size, self_attn, feed_forward, dropout):
158 super(EncoderLayer, self).__init__()
159 self.self_attn = self_attn
160 self.feed_forward = feed_forward
161 self.sublayer = clones(SublayerConnection(size, dropout), 2)
162 self.size = size
163
164 def forward(self, x, mask):
165 "Follow Figure 1 (left) for connections."
166 x = self.sublayer[0](x, lambda x: self.self_attn(x, x, x, mask))
167 return self.sublayer[1](x, self.feed_forward)
168
169
170class Encoder(nn.Module):
171 "Core encoder is a stack of N layers"
172
173 def __init__(self, layer, N):
174 super(Encoder, self).__init__()
175 self.layers = clones(layer, N)
176 self.norm = LayerNorm(layer.size)
177
178 def forward(self, x, mask):
179 "Pass the input (and mask) through each layer in turn."
180 for layer in self.layers:
181 x = layer(x, mask)
182 return self.norm(x)
183
184
185class DecoderLayer(nn.Module):
186 "Decoder is made of self-attn, src-attn, and feed forward (defined below)"
187
188 def __init__(self, size, self_attn, src_attn, feed_forward, dropout):
189 super(DecoderLayer, self).__init__()
190 self.size = size
191 self.self_attn = self_attn
192 self.src_attn = src_attn
193 self.feed_forward = feed_forward
194 self.sublayer = clones(SublayerConnection(size, dropout), 3)
195
196 def forward(self, x, memory, src_mask, tgt_mask):
197 "Follow Figure 1 (right) for connections."
198 m = memory
199 x = self.sublayer[0](x, lambda x: self.self_attn(x, x, x, tgt_mask))
200 x = self.sublayer[1](x, lambda x: self.src_attn(x, m, m, src_mask))
201 return self.sublayer[2](x, self.feed_forward)
202
203
204class Decoder(nn.Module):
205 "Generic N layer decoder with masking."
206
207 def __init__(self, layer, N):
208 super(Decoder, self).__init__()
209 self.layers = clones(layer, N)
210 self.norm = LayerNorm(layer.size)
211
212 def forward(self, x, memory, src_mask, tgt_mask):
213 for layer in self.layers:
214 x = layer(x, memory, src_mask, tgt_mask)
215 return self.norm(x)

218class EncoderDecoder(nn.Module):
219 """
220 A standard Encoder-Decoder architecture. Base for this and many
221 other models.
222 """
223
224 def __init__(self, encoder, decoder, src_embed, tgt_embed, generator):
225 super(EncoderDecoder, self).__init__()
226 self.encoder = encoder
227 self.decoder = decoder
228 self.src_embed = src_embed
229 self.tgt_embed = tgt_embed
230 self.generator = generator
231
232 def forward(self, src, tgt, src_mask, tgt_mask):
233 "Take in and process masked src and target sequences."
234 return self.decode(self.encode(src, src_mask), src_mask, tgt, tgt_mask)
235
236 def encode(self, src, src_mask):
237 return self.encoder(self.src_embed(src), src_mask)
238
239 def decode(self, memory, src_mask, tgt, tgt_mask):
240 return self.decoder(self.tgt_embed(tgt), memory, src_mask, tgt_mask)

243class Generator(nn.Module):
244 "Define standard linear + softmax generation step."
245
246 def __init__(self, d_model, vocab):
247 super(Generator, self).__init__()
248 self.proj = nn.Linear(d_model, vocab)
249
250 def forward(self, x):
251 return log_softmax(self.proj(x), dim=-1)

254def make_model(
255 src_vocab, tgt_vocab, N=6, d_model=512, d_ff=2048, h=8, dropout=0.1
256):
257 "Helper: Construct a model from hyperparameters."
258 c = copy.deepcopy
259 attn = MultiHeadedAttention(h, d_model)
260 ff = PositionwiseFeedForward(d_model, d_ff, dropout)
261 position = PositionalEncoding(d_model, dropout)
262 model = EncoderDecoder(
263 Encoder(EncoderLayer(d_model, c(attn), c(ff), dropout), N),
264 Decoder(DecoderLayer(d_model, c(attn), c(attn), c(ff), dropout), N),
265 nn.Sequential(Embeddings(d_model, src_vocab), c(position)),
266 nn.Sequential(Embeddings(d_model, tgt_vocab), c(position)),
267 Generator(d_model, tgt_vocab),
268 )
269
270 # This was important from their code.
271 # Initialize parameters with Glorot / fan_avg.
272 for p in model.parameters():
273 if p.dim() > 1:
274 nn.init.xavier_uniform_(p)
275 return model

278def greedy_decode(model, src, src_mask, max_len, start_symbol):
279 memory = model.encode(src, src_mask)
280 ys = torch.zeros(1, 1).fill_(start_symbol).type_as(src.data)
281 for i in range(max_len - 1):
282 out = model.decode(
283 memory, src_mask, ys, subsequent_mask(ys.size(1)).type_as(src.data)
284 )
285 prob = model.generator(out[:, -1])
286 _, next_word = torch.max(prob, dim=1)
287 next_word = next_word.data[0]
288 ys = torch.cat(
289 [ys, torch.zeros(1, 1).type_as(src.data).fill_(next_word)], dim=1
290 )
291 return ys

294class Batch:
295 """Object for holding a batch of data with mask during training."""
296
297 def __init__(self, src, tgt=None, pad=2): # 2 = <blank>
298 self.src = src
299 self.src_mask = (src != pad).unsqueeze(-2)
300 if tgt is not None:
301 self.tgt = tgt[:, :-1]
302 self.tgt_y = tgt[:, 1:]
303 self.tgt_mask = self.make_std_mask(self.tgt, pad)
304 self.ntokens = (self.tgt_y != pad).data.sum()
305
306 @staticmethod
307 def make_std_mask(tgt, pad):
308 "Create a mask to hide padding and future words."
309 tgt_mask = (tgt != pad).unsqueeze(-2)
310 tgt_mask = tgt_mask & subsequent_mask(tgt.size(-1)).type_as(
311 tgt_mask.data
312 )
313 return tgt_mask

316class LabelSmoothing(nn.Module):
317 "Implement label smoothing."
318
319 def __init__(self, size, padding_idx, smoothing=0.0):
320 super(LabelSmoothing, self).__init__()
321 self.criterion = nn.KLDivLoss(reduction="sum")
322 self.padding_idx = padding_idx
323 self.confidence = 1.0 - smoothing
324 self.smoothing = smoothing
325 self.size = size
326 self.true_dist = None
327
328 def forward(self, x, target):
329 assert x.size(1) == self.size
330 true_dist = x.data.clone()
331 true_dist.fill_(self.smoothing / (self.size - 2))
332 true_dist.scatter_(1, target.data.unsqueeze(1), self.confidence)
333 true_dist[:, self.padding_idx] = 0
334 mask = torch.nonzero(target.data == self.padding_idx)
335 if mask.dim() > 0:
336 true_dist.index_fill_(0, mask.squeeze(), 0.0)
337 self.true_dist = true_dist
338 return self.criterion(x, true_dist.clone().detach())

341class SimpleLossCompute:
342 "A simple loss compute and train function."
343
344 def __init__(self, generator, criterion):
345 self.generator = generator
346 self.criterion = criterion
347
348 def __call__(self, x, y, norm):
349 x = self.generator(x)
350 sloss = (
351 self.criterion(
352 x.contiguous().view(-1, x.size(-1)), y.contiguous().view(-1)
353 )
354 / norm
355 )
356 return sloss.data * norm, sloss
